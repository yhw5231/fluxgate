上游通道

通道把一个上游账号（以及可选的账号令牌）挂到一条路由上。同一路由下优先级最高的通道优先被选中，同优先级之间按权重轮询。

还没有通道。先添加站点、账号和路由，再把它们连起来。

路由

路由决定客户端请求哪个模型名时由哪些通道回应。模型名支持 *、? 通配符，以 re: 开头则按正则匹配。

还没有路由。没有路由时网关不会向上游转发任何请求。

站点

站点是一个上游服务的地址。只有状态为 active 的站点才会参与选路。

还没有站点。

账号

账号是站点上的一份凭据。访问令牌按写入保存，读取时只显示末四位。

还没有账号。

账号令牌

一个账号可以带多个令牌，通道可以指定使用其中某一个；不指定时使用账号本身的访问令牌。

还没有令牌。

代理

代理按「令牌/账号 → 站点 → 默认代理 → 系统代理 → 直连」的顺序生效。站点和账号上的代理地址优先于这里的默认代理。
